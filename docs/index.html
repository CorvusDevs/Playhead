The problem

Your Mac cannot open half your files

Press space on a Matroska file and Finder shrugs. QuickTime refuses it outright. The tools that do read it hand back three hundred fields and leave you to work out which ones matter.

Playhead reads the file with the same library the professionals use, then answers the question you actually asked: what is this, will it play, and is anything wrong with it.

Tracks

See the shape of the file, not just a list

A list tells you a film has twelve subtitle tracks. It cannot tell you that one of them appears for ninety seconds in the middle, which is what a forced narrative track looks like, or that the second audio track stops at the credits.

Playhead lays every track on one clock: the picture as a filmstrip, each sound track named by its own title, each subtitle track drawn where it actually appears.

Colour

HDR, in the words people use

Most tools report the format as "SMPTE ST 2086" and leave the name you recognise in a different field. Playhead leads with HDR10 or Dolby Vision, says what a player without it falls back to, and turns the mastering data into brightness you can read: the monitor it was graded on, the brightest pixel, the brightest frame.

Compatibility

Measured on your Mac, not looked up in a table

Other tools guess from rules like "10-bit 4:2:2 usually lacks hardware decoding". Rules like that are wrong on some machines the day they are written.

Playhead hands your file's own codec configuration to VideoToolbox and asks your Mac directly, so the answer accounts for the exact profile, depth and chroma in front of you. It also checks the frame rate against your display's refresh rate, and whether your screen can actually show HDR.

Photos

Every photo, and what the camera recorded

Open a JPEG, HEIC or raw file and Playhead reads the camera, the lens, the shutter, the aperture and the ISO, along with the copyright and caption fields.

If the photo still carries the coordinates of where it was taken, Playhead says so plainly, before you share it with anyone.

Questions

Frequently asked

How is this different from MediaInfo?

Playhead reads the same data, using the same underlying library, and keeps every field available. The difference is what happens next: it names what the file is in a sentence, shows the tracks on a timeline, and answers whether the file will play on the machine you are sitting at. MediaInfo is free and excellent at collecting information; Playhead is about understanding it.

What formats can it read?

Matroska, MP4, QuickTime, WebM, AVI, MPEG-TS, Ogg, FLAC, WAV, MP3 and many more, plus still images including JPEG, PNG, HEIC, TIFF and raw files. Frames are extracted for H.264, H.265, AV1, VP8 and VP9.

Does it modify my files?

No. Playhead opens files read only and never writes to them.

Is it one purchase for both platforms?

Yes. Playhead is a universal purchase, so buying it once covers your Mac, iPhone and iPad.

Why can it open files QuickTime cannot?

It does not rely on the system's media stack alone. It bundles the same open-source libraries used across the industry to read containers and demux streams, then hands decoding back to Apple's own hardware decoder.

Does it need an internet connection?

No. It never makes one.
